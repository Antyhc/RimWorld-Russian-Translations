# Публикация / Publishing

Предпочтительный результат — русский язык внутри оригинального мода.
Сначала проверьте официальный репозиторий, текущую ветку, лицензию и правила
вклада. Не отправляйте PR с пересказом устаревшей Workshop-версии в неподходящую
ветку. В обращении укажите помощь ИИ, точный объём проверки и отсутствие
игрового теста, если его не было. Не приписывайте автору согласие до ответа.

Для отдельного русификатора обязательны:

- подтверждённые права на каждую распространяемую часть и сохранённые уведомления;
- проверка актуальных существующих русификаторов и отсутствия эквивалентного дубля;
- уникальный PackageId, зависимость и `loadAfter` оригинала;
- только заявленные проверяемые версии и файлы русской локализации;
- технические и смысловые проверки, связанные с хешами точного набора файлов;
- отдельно подтверждённые права на оригинальную обложку и добавление `RUSSIAN`.

Скрипт `scripts/cover.py` накладывает только надпись и подложку. Его вход —
разрешённое оригинальное изображение, права с доказательством в манифесте
и установленный шрифт. Оригинальные размеры и пропорции сохраняются. Скрипт
не предоставляет права на изображение; без разрешения он отказывается работать.

`stage` собирает новый каталог только после прохождения ограничений. Для выпуска
нужен ручной визуальный просмотр обложки и интерфейса. Перед загрузкой сверяются
зависимости и текущая версия Steam Workshop. Пакет должен включать уведомления
о лицензиях, когда они требуются. При отсутствии прав на обложку публикация
по стандарту этого проекта остаётся заблокированной.

Загрузка Workshop выполняется из авторизованного Steam/RimWorld uploader.
Автоматическая загрузка без сессии и принятия требуемых Steam соглашений здесь
не реализована. После загрузки необходимо проверить публичную страницу,
обязательную зависимость, подписку/установку и фактическую загрузку игры.
Только затем записываются подтверждённые Workshop ID/URL.

Коллекция: **RimWorld — Russian Translations Collection**.
Её тексты находятся в `community/collection-description.md`; в неё включаются
только реально опубликованные нами переводы. Если перевод принят оригиналом,
обновите описание отдельной публикации и коллекции, не удаляя историю и
публикацию без оценки последствий подписчикам.

Статусы интеграции: `ready`, `proposed`, `pr_submitted`, `awaiting_response`,
`accepted`, `changes_requested`, `rejected`, `contact_unavailable`.
Журнал контактов находится в `community/outreach.json`; URL и дата позволяют
избежать дублирования обращений.
