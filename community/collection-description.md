# RimWorld — Russian Translations Collection

## Русский

Русские переводы модификаций RimWorld с прозрачным учётом авторства, версий,
проверок и предложений интеграции в оригинальные моды.

Подпишитесь на оригинальный мод по ссылке в описании русификатора и на сам
русификатор. Загружайте перевод после оригинала и выберите русский язык игры.
Поддерживаемую версию проверяйте на странице каждого перевода. Не включайте
две копии одного русификатора одновременно.

Исходники и реестр: https://github.com/Antyhc/RimWorld-Russian-Translations
Ошибки перевода: https://github.com/Antyhc/RimWorld-Russian-Translations/issues

Переводы подготовлены с помощью ИИ; фактические проверки указаны для каждого
пакета. Оригинальные моды и иллюстрации принадлежат их авторам. Если русский
язык принят автором оригинала, информация об отдельном переводе обновляется.

## English

Russian localizations for RimWorld mods, with per-mod credits, supported versions,
validation evidence and upstream integration tracking.

Subscribe to both the original mod and its translation. Load the translation after
the original and select Russian in RimWorld. Check the supported game version on
each translation page. Enable only one copy of each translation.

Sources and registry: https://github.com/Antyhc/RimWorld-Russian-Translations
Translation issues: https://github.com/Antyhc/RimWorld-Russian-Translations/issues

Translations are AI-assisted; actual checks are listed per package. Original mods
and artwork belong to their respective authors. When Russian is integrated upstream,
the separate translation's status is updated accordingly.
