# RimWorld — русские переводы модов

[English](README.en.md) · [Реестр](registry.json) · [Состояние проекта](PROJECT_STATUS.md) · [Правила добавления](CONTRIBUTING.md)

Проект сопровождения русских локализаций RimWorld. Сначала предлагаем перевод
автору оригинала; отдельный пакет Workshop выпускаем только при подтверждённых
правах, проверке актуальности и отсутствии качественного актуального аналога.

На 28 октября 2026 года проинвентаризированы **156 локализаций** существующего
локального проекта. Запись в реестре означает учёт работы: она сама по себе
не означает наличие опубликованного перевода, разрешение правообладателя или
успешный игровой тест. Поля `publication` и `qa` фиксируют эти результаты отдельно.
Непроверенные машинные черновики в публичные пакеты не включаются.

Первые предложения интеграции: [Designator Shapes, 208 строк](https://github.com/merthsoft/designator-shapes/pull/15)
и [No Burn Metal, 19 строк интерфейса](https://github.com/Nonunon/NoBurnMetal/pull/1).
Их русские исходники доступны в соответствующих `mods/` директориях. Отдельные
Workshop-выпуски пока удержаны до проверки существующих аналогов и прав на
обложки. Для 24 подтверждённых официальных репозиториев настроен ежедневный
монитор файлов; остальные записи явно остаются без сетевого мониторинга.

## Установка

Откройте нужный `mods/<packageId>/manifest.json`. Установите оригинальный мод по
`original.workshop_url`. Если у перевода есть `publication.workshop_url`, подпишитесь
и на него. При ручной установке скопируйте **только содержимое `payload/`**
в отдельный каталог `RimWorld/Mods/`, после чего включите оригинал и русификатор.
Порядок: оригинал → русификатор; язык игры — русский. Поддерживаемые версии
указаны в `supported_versions`; наличие 1.7 у оригинала не доказывает поддержку
предыдущих версий переводом. При переходе с локальной копии включайте только
один пакет перевода для каждого оригинала, чтобы избежать повторных ключей.

Если `payload/` отсутствует, эта запись пока не является устанавливаемым модом.
Исторические пакеты пользователя и ранее отредактированные, но ещё не установленные
партии сохраняются отдельно и не выдаются за готовые публичные выпуски.

## Авторы и права

Авторы оригиналов, ссылки и найденные лицензии записаны в каждом манифесте.
Этот проект не распространяет DLL, текстуры или исходные игровые ресурсы.
Переводы сообщества сохраняют своё авторство и лицензию; известный источник
[Vanilla Russian Expanded](https://github.com/OneCodeUnit/VanillaRussianExpanded)
использует CC BY-NC-SA 4.0. Его пакеты не следует дублировать автоматически.
Наличие текста из этого источника в локальном проекте не означает, что он уже
перепубликован здесь.

Переводы подготовлены с участием ИИ. `ai_reviewed` означает смысловую проверку
ИИ по исходнику; это не независимая редактура человеком. Статические проверки,
загрузка в игру и проверка интерфейса/игрового процесса учитываются отдельно.
Обложка оригинала с надписью `RUSSIAN` допускается только при отдельном
подтверждении прав на изображение и его изменение. Лицензия программного кода
не считается автоматическим разрешением на стороннюю иллюстрацию.

## Сопровождение

Архитектура не ограничивает количество модов: инструменты находят
`mods/*/manifest.json` автоматически. Новые и изменённые строки получают очередь
редактуры, существующий русский текст сохраняется. Подробности и команды:
[инструменты](docs/MAINTENANCE.md), [публикация](docs/PUBLISHING.md),
[ограничения проверок](docs/QA.md), [история](CHANGELOG.md).

Ошибки сообщайте через [Issues](https://github.com/Antyhc/RimWorld-Russian-Translations/issues),
указав название мода, версию игры, ключ/скриншот и ожидаемый перевод. Не прикладывайте
данные авторизации Steam/GitHub или личные сохранения без проверки их содержимого.

Коллекция Workshop будет связана здесь после фактического создания и проверки
первого выпуска. До этого ссылки и статусы не подменяются предполагаемыми.
