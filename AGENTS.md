# Project instructions

Read README.md, CONTRIBUTING.md, PROJECT_STATUS.md and the selected mod's manifest.
The public registry includes pending inventory records, not only released packages.
Discover manifests by glob; do not introduce a hardcoded mod list.
Preserve existing reviewed Russian text, attribution, source hashes and remote URLs.
Check native and current third-party Russian translations before duplicating them.
Unknown translation/image rights block distribution of the affected material.
Do not include original DLLs/textures, private paths, logs, credentials or machine caches.
Record AI assistance honestly; distinguish automated checks, AI/human editing and game tests.
Prefer upstream integration; follow upstream contribution/AI rules before sending a PR.
Keep contacts specific and deduplicated; do not send bulk messages.
Do not claim a publication, permission, merge or game test without verified evidence.
Every state change updates the manifest and generated registry/PROJECT_STATUS.md.
Use scripts/rwtranslations.py and run relevant tests before publishing tooling changes.
Workshop release and collection URLs must be actual verified results, never guessed.
