# История изменений / Changelog

## 2026-10-28 — создание публичной структуры

- Продолжен существующий локальный проект без повторного перевода коллекции.
- Создана инвентаризация 156 пакетов и отдельный учёт прав, QA и публикаций.
- Статическая проверка установленного набора: 1 408 XML; 53 061 сравнение
  с сохранёнными английскими строками. Выявлены дрейф исходников,
  устаревшие доказательства полей и три расхождения с сохранёнными переводами.
- Подготовлены автоматическая генерация реестра, проверка пакетов,
  отчёты изменений и очередь редактуры, CI и шаблоны сопровождения.
- Статусы публикаций и upstream PR фиксируются в манифестах по фактическому результату.

Новый игровой тест этой публикационной работой пока не подтверждён.
